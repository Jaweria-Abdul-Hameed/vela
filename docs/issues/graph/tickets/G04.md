# G04: Merge operations: integration merge into branch, no-ff merge, discard unpublished merge, conflict detection

**Planned labels:** `type:feature` `area:git` `risk:high` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 6 · **Direct blockers (published, transitively reduced):** G02, G03

> Symbolic key: `G04` · Area: git · Phase: 1 · Risk: high

## 2. Objective
The deterministic lane has the Git operations it needs, with no rebase and no force-push.

## 3. Requirement IDs
FR-017

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Merge integration tip into a worker branch; non-fast-forward merge with trailers in the integration worktree; reset of a clean Vela-managed integration worktree to a recorded SHA for an unpublished merge; conflict reports; ancestry verification.

## 6. Architectural constraints
- Shell out to the git binary under the verified hardened invocation (IMPLEMENTATION_ARCHITECTURE.md; no libgit2).
- Never force-push; never rebase pushed branches; never touch the primary checkout working tree, index, or branch (ADR-011).
