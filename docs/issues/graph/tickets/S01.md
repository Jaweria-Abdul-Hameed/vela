# S01: Project import: choose a repository, persist it, and list recent projects

**Planned labels:** `type:feature` `area:orchestration` `risk:low` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 5 · **Direct blockers (published, transitively reduced):** F08

> Symbolic key: `S01` · Area: orchestration · Phase: 1 · Risk: low

## 2. Objective
The user can add a repository folder, see it in a recent list, remove it from Vela without touching the repository, and resume it after restart.

## 3. Requirement IDs
FR-001, AT-001

## 4. User-visible behavior
A minimal home list and folder picker (visual polish arrives with the home scene).

## 5. Technical scope
- project.import/list/remove/open commands and persistence; invalid-folder handling; project record with repository identity.
- Minimal renderer surface wired to the gateway.

## 6. Architectural constraints
- The Orchestrator is the only writer of orchestration state; each transition is one transaction (state plus journal) (ADR-002, ADR-017).
- Events reach the UI only after commit.
- Scheduler never assumes a UI is open.

## 7. Dependencies / blocked by
- F08 IPC gateway: command registry, snapshot plus sequenced event stream, resync
