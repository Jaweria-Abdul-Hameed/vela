> Symbolic key: `A02` · Area: antigravity · Phase: 1 · Risk: high

## 2. Objective
Agent output is parsed into normalized events and outcomes without trusting exit code or status.

## 3. Requirement IDs

## 5. Technical scope
- Parser for init, step_update, and result events; soft-denial detection (stderr and empty result); hook-denial step errors; quota text; auth errors; recorded Section S transcripts as fixtures; malformed-event handling.

- Never read, copy, or persist Antigravity credentials or tokens (ADR-016).
- Elements tagged [U] are gated by their spike; do not claim them ready.
