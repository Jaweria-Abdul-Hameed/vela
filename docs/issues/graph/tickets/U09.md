# U09: Floating run bar: worker count, status, mode, pause, and an always reachable Stop All

**Planned labels:** `type:feature` `area:ui` `risk:medium` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 12 · **Direct blockers (published, transitively reduced):** R04, U01

> Symbolic key: `U09` · Area: ui · Phase: 5 · Risk: medium

## 2. Objective
A minimal floating control shows run status and offers pause and Stop All, reachable by keyboard and without precise pointing, with the approval indicator.

## 3. Requirement IDs
FR-021, NFR Accessibility, AT-006

## 4. User-visible behavior
A quiet capsule; inline non-modal Stop All confirmation that can be configured off; approval indicator states.

## 5. Technical scope
- Run bar; Stop All control and configurable shortcut; confirmation behavior; approval indicator (active, waiting on human, degraded).

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- R04 Stop All, pause, and resume for running workers
- U01 Design system: tokens, typography, restrained glass, icons, and the base shell

## 8. Expected write surfaces

## 9. Known shared contracts
