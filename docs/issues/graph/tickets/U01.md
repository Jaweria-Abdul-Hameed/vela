# U01: Design system: tokens, typography, restrained glass, icons, and the base shell

**Planned labels:** `type:feature` `area:ui` `risk:low` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 4 · **Direct blockers (published, transitively reduced):** F05

> Symbolic key: `U01` · Area: ui · Phase: 5 · Risk: low

## 2. Objective
The renderer has the near-black design tokens, type scale, glass surface component, icon set, and a base shell with no permanent sidebar.

## 3. Requirement IDs
FR-025, FR-026, AT-008

## 4. User-visible behavior
A calm near-black window with quiet branding and no dashboard chrome.

## 5. Technical scope
- CSS-variable tokens (canvas, surface, text, violet/blue/cyan light, status families), type scale, spacing, radius, borders; glass component used only for floating surfaces; single geometric icon family; base shell and focus-ring styles independent of glow.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- F05 Renderer skeleton: React, store, IPC wrappers, and front-end test tooling
