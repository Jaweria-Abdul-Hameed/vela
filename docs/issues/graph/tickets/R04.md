# R04: Stop All, pause, and resume for running workers

**Planned labels:** `type:feature` `area:recovery` `risk:high` `phase:3` `ready-for-agent`  
**Depth in the DAG:** 12 · **Direct blockers (published, transitively reduced):** P02, S11

> Symbolic key: `R04` · Area: recovery · Phase: 3 · Risk: high

## 2. Objective
Stop All halts all running workers safely with preserved work, and pause and resume work after reconciliation.

## 3. Requirement IDs
FR-021, FR-022

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- STOPPING with graceful then forced cancellation of Vela-created sessions and process trees; pause reasons; resume after reconciliation; never touches non-Vela Antigravity processes.

## 6. Architectural constraints
- Persist intent before every non-idempotent external action and the observed result after; never guess after divergence.
- Never replay a stale UI click.

## 7. Dependencies / blocked by
- P02 Process tree kill and cancellation
- S11 Checkpoint and review loop with a fake reviewer: fixed point, findings, fix loop, cap

## 8. Expected write surfaces

## 9. Known shared contracts

## 11. Acceptance criteria

- [ ] Branches, worktrees, and commits are preserved, and only Vela-created sessions and process trees are terminated.
- [ ] After reconciliation, Resume continues from the recorded state.
