# U10: Intervention sheet for every intervention kind

**Planned labels:** `type:feature` `area:ui` `risk:medium` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 7 · **Direct blockers (published, transitively reduced):** S15, U01

> Symbolic key: `U10` · Area: ui · Phase: 5 · Risk: medium

## 2. Objective
Each NEEDS_HUMAN kind appears as an actionable card with the exact blocking state, preserved work, last safe commit, evidence, actions, and consequences.

## 3. Requirement IDs
FR-020, AT-010

## 4. User-visible behavior
A glass sheet in calm operational language for review stalled, merge conflict, approval ask/stalled/undeliverable, policy denied/violation, integration regression, auth required, divergence, graph invalid.

## 5. Technical scope
- Sheet and per-kind variants; actions resolve through intervention.resolve; copy per COPY_AND_TONE.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- S15 Human intervention model: records, kinds, resume state, decisions
- U01 Design system: tokens, typography, restrained glass, icons, and the base shell

## 8. Expected write surfaces
- apps/desktop/src/surfaces/intervention/**

## 9. Known shared contracts
- packages/contracts generated types
- packages/ui design tokens (CSS variables)
- Store reducer applying EventEnvelope
