# P03: Keep-awake thread and interactive-session probe

**Planned labels:** `type:feature` `area:process` `risk:medium` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 2 · **Direct blockers (published, transitively reduced):** F02

> Symbolic key: `P03` · Area: process · Phase: 1 · Risk: medium

## 2. Objective
During an active run Vela can hold the system awake and can tell whether an interactive unlocked desktop is available.

## 3. Requirement IDs
FR-041, AT-017

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Dedicated thread setting and clearing the execution state; SessionProbe implementation (input desktop reachability).

## 6. Architectural constraints
- Windows-aware; process trees are tracked so cancellation and reconciliation find every child.
- All captured output passes through the central redaction layer.

## 7. Dependencies / blocked by
