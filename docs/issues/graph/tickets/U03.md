# U03: Ambient violet, blue, and cyan field with Full, Balanced, and Efficiency graphics modes

**Planned labels:** `type:feature` `area:ui` `risk:medium` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 6 · **Direct blockers (published, transitively reduced):** U02, S02

> Symbolic key: `U03` · Area: ui · Phase: 5 · Risk: medium

## 2. Objective
Huge soft gradient masses drift very slowly behind the dots, and the user can choose a graphics mode with a documented effect on cost.

## 3. Requirement IDs
FR-026, FR-027, AT-009

## 4. User-visible behavior
Volumetric color on a black canvas; Settings control for Full, Balanced (default), Efficiency; automatic adaptation only suggests.

## 5. Technical scope
- Ambient shader or gradient primitives; quality parameters (pixel ratio cap, effects, density, frame cap, idle suspension); settings wiring; suggestion UI.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- U02 Canvas foundation: reactive dot lattice with demand rendering and suspension
- S02 Settings layers, onboarding choices, and the immutable run snapshot
