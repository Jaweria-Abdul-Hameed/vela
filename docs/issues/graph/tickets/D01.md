# D01: State machines: run, worker, and ticket projection with exhaustive transition tests

**Planned labels:** `type:feature` `area:domain` `risk:high` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 2 · **Direct blockers (published, transitively reduced):** F02

> Symbolic key: `D01` · Area: domain · Phase: 1 · Risk: high

## 2. Objective
The run machine, worker machine, intervention kinds, and ticket/UI projection exist as pure tables with exhaustive and property tests.

## 3. Requirement IDs
FR-019, FR-020, FR-021, FR-022

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Run states and transition table including STOPPING, PAUSED reasons, resume_state, integration_health; worker states including CONFLICT_RESOLUTION and the WAITING_APPROVAL overlay; NEEDS_HUMAN kinds, including `PROVIDER_POLICY_BLOCK` at worker and run level (ORCHESTRATION_ENGINE.md section 3.2).
- Ticket state projection and UI node mapping per DOMAIN_MODEL.md; illegal transitions return typed errors.

## 6. Architectural constraints
- vela-domain depends on no other Vela crate and has no I/O (pure logic).
- Provider-specific concepts do not leak into domain types (ADR-006).

## 7. Dependencies / blocked by
- F02 Domain primitives, ports, and TypeScript contract generation

## 8. Expected write surfaces
- crates/vela-domain/src/state/**

## 9. Known shared contracts
- vela-domain::ports traits
- ts-rs exported DTOs in packages/contracts
- Transition tables (consumed by Orchestrator and UI node mapping)

## 10. Parallelization notes
Parallel with D02, D05, D06 after F02 (disjoint modules).

## 11. Acceptance criteria
- [ ] Every transition in ORCHESTRATION_ENGINE.md section 1.1 and the worker machine is implemented; every other transition is rejected.
- [ ] The projection covers every worker state and intervention kind.
- [ ] `PROVIDER_POLICY_BLOCK` is a worker-level and run-level kind from which no transition leaves automatically: the only exits are an explicit resolve to `resume_state` or a cancel.
- [ ] Property test: no sequence of legal transitions reaches an unmapped state.
