# U04: Home scene: drop a project folder, recent project anchors, and the import flow

**Planned labels:** `type:feature` `area:ui` `risk:low` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 6 · **Direct blockers (published, transitively reduced):** S01, U02

> Symbolic key: `U04` · Area: ui · Phase: 5 · Risk: low

## 2. Objective
The home canvas invites the user to drop a repository folder and shows recent projects as quiet anchors.

## 3. Requirement IDs
FR-001, AT-008

## 4. User-visible behavior
Large soft typography, one primary action, restrained translucent drop zone, recent projects as floating pills; invalid folder and loading states.

## 5. Technical scope
- Home scene composition; drag/drop and picker wired to project.import; recent anchors; empty, invalid, and loading states.
- Replaces the S01 placeholder project list: the placeholder surface and its test are removed here.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- S01 Project import: choose a repository, persist it, and list recent projects
- U02 Canvas foundation: reactive dot lattice with demand rendering and suspension

## 8. Expected write surfaces
- apps/desktop/src/scenes/home.tsx

## 9. Known shared contracts
- packages/contracts generated types
- packages/ui design tokens (CSS variables)
- Store reducer applying EventEnvelope
