## 2. Objective
Stop All during a merge or push reaches a safe point or marks integration health UNKNOWN so reconciliation decides before resume.

## 3. Requirement IDs
FR-021, FR-022, AT-006

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Declares FaultPoints at the bounded-wait expiry and the discard-versus-abandon decision (SHARED_SURFACE_PROTOCOL.md section 6); R03 adds the matrix entries.
- A merge completes validation or is discarded to the recorded integration_before; a push completes or is abandoned; otherwise integration_health becomes UNKNOWN and the run requires reconciliation; bounded wait; journaling.

## 6. Architectural constraints
- Persist intent before every non-idempotent external action and the observed result after; never guess after divergence.
- Never replay a stale UI click.
