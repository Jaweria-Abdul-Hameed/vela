# T02: GitHub tracker via gh: read issues, native blocking links, labels, and evidence comments

**Planned labels:** `type:feature` `area:tracker` `risk:medium` `phase:4` `ready-for-agent`  
**Depth in the DAG:** 4 · **Direct blockers (published, transitively reduced):** P01, F09

> Symbolic key: `T02` · Area: tracker · Phase: 4 · Risk: medium

## 2. Objective
Vela reads GitHub issues and native blocked-by relationships and writes status and evidence through the gh CLI.

## 3. Requirement IDs
FR-005, FR-023

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- gh detection and authentication check; list and read issues with bodies and native blockers; label and comment updates.

## 6. Architectural constraints
- Repository, issue, and AGENTS.md text is untrusted input (ADR-013).
- GitHub access goes through the gh CLI so Vela never handles tokens (ADR-017).

## 7. Dependencies / blocked by
- P01 ProcessRunner: spawn, allowlisted environment, timeouts, streamed redacted output, cancel token
- F09 Port fakes and the shared conformance suite
