# A14: Antigravity recovery and version drift: orphan sessions, stale profile and spool state, and background self-update

**Planned labels:** `type:feature` `area:antigravity` `risk:medium` `phase:3` `ready-for-agent`  
**Depth in the DAG:** 12 · **Direct blockers (published, transitively reduced):** R02, A03, A05, SP11

> Symbolic key: `A14` · Area: antigravity · Phase: 3 · Risk: medium

## 2. Objective
A background agy or Desktop update during a run is detected as a divergence and capabilities are re-detected before resuming.

## 3. Requirement IDs
FR-037, FR-019, FR-022

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Version snapshot per run; drift detection at turn boundaries and reconciliation; re-run capability and posture probes.
- Antigravity reconciliation recipe registered with R01: identify Vela-created `agy` process trees by recorded identity and report or clean orphans; verify a recorded conversation id and session identity before resume, otherwise start a new session; remove stale per-worker profile directories, spool files, and expired allow rules of workers that are not running; never touch Antigravity processes or sessions Vela did not create.

## 6. Architectural constraints
- Only vela-adapters::antigravity and vela-uia may contain Antigravity-specific behavior (ADR-008, ADR-018).
- Never trust exit code or result.status; interpret events, stderr, and Git state.
- Never read, copy, or persist Antigravity credentials or tokens (ADR-016).
- Elements tagged [U] are gated by their spike; do not claim them ready.

## 7. Dependencies / blocked by
- R02 Startup reconciliation and recovery-resume
- A03 Per-turn session driver: spawn, conversation id, explicit timeout, cancel, resume
- A05 Per-worker profile manager and generated settings and allow rules
- SP11 Spike S-CAP-REMAINING: WAITING status, concurrency ceiling, background self-update control, and interactive TUI behavior

- [ ] Stale profile, spool, and expired-rule state of non-running workers is cleaned or reported, never silently reused.
