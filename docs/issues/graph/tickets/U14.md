# U14: Reduced motion everywhere and the WebGL failure fallback

**Planned labels:** `type:feature` `area:ui` `risk:medium` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 9 · **Direct blockers (published, transitively reduced):** U06

> Symbolic key: `U14` · Area: ui · Phase: 5 · Risk: medium

## 2. Objective
Reduced motion removes camera flight, parallax, ripples, and loops everywhere, and a WebGL failure falls back gracefully.

## 3. Requirement IDs
NFR Accessibility, FR-027

## 4. User-visible behavior
Static indicators and short fades; a one-time notice when falling back to CSS/SVG.

## 5. Technical scope
- Reduced-motion implementation across scenes (OS preference and setting); context-loss, creation-failure, and software-render fallback to CSS gradient, SVG graph, and list view.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- U06 Node states and event-driven effects: ripples, edge flow, settling

## 8. Expected write surfaces
