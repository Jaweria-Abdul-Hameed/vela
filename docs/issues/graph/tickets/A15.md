> Symbolic key: `A15` · Area: antigravity · Phase: 2 · Risk: medium

## 2. Objective
The verified Section S probes are encoded as a repeatable suite that runs only against a real installation and a throwaway repository.

## 3. Requirement IDs
FR-037, AT-015, AT-025

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Suite covering soft-denial, allow rules, hook behavior, skills, resume, kill, isolated profile, and credential non-access; safe-by-default gating; version-stamped results.
- Takes a machine-wide lock for `RK-AGY-REAL-ACCOUNT` (SHARED_SURFACE_PROTOCOL.md section 8) so concurrent real runs cannot confound each other.

## 6. Architectural constraints
- Only vela-adapters::antigravity and vela-uia may contain Antigravity-specific behavior (ADR-008, ADR-018).
- Never trust exit code or result.status; interpret events, stderr, and Git state.
- Never read, copy, or persist Antigravity credentials or tokens (ADR-016).
- Elements tagged [U] are gated by their spike; do not claim them ready.
