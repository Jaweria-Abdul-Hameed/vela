# U02: Canvas foundation: reactive dot lattice with demand rendering and suspension

**Planned labels:** `type:feature` `area:ui` `risk:high` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 4 · **Direct blockers (published, transitively reduced):** F05

> Symbolic key: `U02` · Area: ui · Phase: 5 · Risk: high

## 2. Objective
A single WebGL canvas draws an ordered, sparse dot lattice that responds smoothly to the pointer and renders only on demand.

## 3. Requirement IDs
FR-026, FR-027, AT-008, AT-009

## 4. User-visible behavior
Tiny dots displace, brighten, and spring back near the cursor; no chaotic particle motion.

## 5. Technical scope
- packages/ui/src/canvas as the only Three.js/R3F importer; dot shader with bounded pointer influence and spring return; frameloop on demand; suspend and resume on hidden, minimized, and blurred; dispose resources.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- F05 Renderer skeleton: React, store, IPC wrappers, and front-end test tooling

## 8. Expected write surfaces

## 9. Known shared contracts
