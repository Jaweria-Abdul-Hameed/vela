# U05: Project universe: dependency constellation rendering, camera, and fit view

**Planned labels:** `type:feature` `area:ui` `risk:high` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 7 · **Direct blockers (published, transitively reduced):** U02, S06, U01

> Symbolic key: `U05` · Area: ui · Phase: 5 · Risk: high

## 2. Objective
The project graph renders as a constellation of nodes and fine luminous edges with pan, zoom, fit, and reset, using the stored layout.

## 3. Requirement IDs
FR-025, AT-008

## 4. User-visible behavior
Nodes as stars, dependencies as fine curves, camera that preserves orientation; transition from home without a hard cut.

## 5. Technical scope
- Instanced node and edge rendering; stored layout consumption; wheel/pinch zoom, drag pan, fit and reset; DOM labels projected over the canvas; scene transition.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- U02 Canvas foundation: reactive dot lattice with demand rendering and suspension
- S06 Issue ingestion to an approved-ready graph snapshot with cycle reporting
- U01 Design system: tokens, typography, restrained glass, icons, and the base shell
