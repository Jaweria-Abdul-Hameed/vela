# L01: Onboarding experience: consent choices, background, auto-start, recovery continuation

**Planned labels:** `type:feature` `area:lifecycle` `risk:low` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 7 · **Direct blockers (published, transitively reduced):** U15

> Symbolic key: `L01` · Area: lifecycle · Phase: 5 · Risk: low

## 2. Objective
First run presents the explicit, conservative onboarding choices and records consent with the consent text version.

## 3. Requirement IDs
FR-040, FR-042, AT-016

## 4. User-visible behavior
A calm onboarding sheet; each choice is skippable and defaults to off or ask; revisitable from Settings.

## 5. Technical scope
- Onboarding surface wired to settings; consent text versioning; revoke flows.
- The consent revoke flows live in the Settings sheet's Automation section, registered through the section registry that U15 delivers.

## 6. Architectural constraints
- Background operation, auto-start, and consent are opt-in and persisted (ADR-010, ADR-012).
- Closing the window never silently abandons work.

## 7. Dependencies / blocked by
- U15 Command palette and settings sheet

## 8. Expected write surfaces
