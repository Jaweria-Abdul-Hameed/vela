# K10: Antigravity preflight providers and unattended readiness: capabilities, authentication, skills, posture, and UI-automation consent

**Planned labels:** `type:feature` `area:broker` `risk:medium` `phase:3` `ready-for-agent`  
**Depth in the DAG:** 10 · **Direct blockers (published, transitively reduced):** A06, K06, P03, U11, A08

> Symbolic key: `K10` · Area: broker · Phase: 3 · Risk: medium

## 2. Objective
Preflight reports the Antigravity capability contract, authentication state, skills, native posture, UI-automation consent and capability, interactive-session conditions, and the expected unattended readiness.

## 3. Requirement IDs
FR-036, AT-015, FR-002, FR-004, FR-037, FR-049

## 4. User-visible behavior
Unattended-readiness summary in the preflight panel.

## 5. Technical scope
- Aggregate posture result (A06), consent state, UIA capability probe, session conditions; Autonomous BLOCK or Supervised WARN with acknowledgement.
- Registers Antigravity check providers with the S04 engine: capability report (A01), AUTH_REQUIRED, skills (A08), native posture (A06), UI-automation consent and capability, and interactive-session conditions; the rows appear in the panel that U11 delivers.

## 6. Architectural constraints
- Policy and delivery are separate; no adapter decides safety (ADR-007).
- Vela approves operations, not buttons; fail closed on any ambiguity.
- UI automation is opt-in and consent-gated (ADR-010).

## 7. Dependencies / blocked by
- A06 Native policy enforcement and the posture probe (MEETS, DOES_NOT_MEET, UNKNOWN)
- K06 vela-uia delivery: single-use allow or refusal through patterns, never persistent options
- P03 Keep-awake thread and interactive-session probe
- U11 Build-ready view and preflight panel with parallelization reasoning
- A08 Skills detection and bootstrap for worker worktrees
