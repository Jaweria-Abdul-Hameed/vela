## 2. Objective
An independent reviewer compares the running UI to the canonical reference image `docs/ui/reference/vela-stitch-reference.png`, inspected directly, and records blocking fidelity findings.

## 3. Requirement IDs

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Independent review using the UI acceptance checklist; classify BLOCKING FIDELITY, IMPORTANT, POLISH, SUBJECTIVE; fix only the first two.
- Inspect the PNG itself rather than relying on prose or earlier conversation. Compare the page area only: ignore the browser frame and the Stitch branding, copy, and layout, which Vela must not clone.
- Where the image is silent (graph, node states, interaction, camera, accessibility, reduced motion, performance, approval, recovery, Stop All), the written specifications govern; the image never overrides them.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.
