# A03: Per-turn session driver: spawn, conversation id, explicit timeout, cancel, resume

**Planned labels:** `type:feature` `area:antigravity` `risk:high` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 5 · **Direct blockers (published, transitively reduced):** A01, P02, TK1

> Symbolic key: `A03` · Area: antigravity · Phase: 1 · Risk: high

## 2. Objective
Vela runs one agy process per turn in a worktree, records the conversation id, and continues a conversation with --conversation.

## 3. Requirement IDs
FR-009, FR-011, FR-037, AT-005

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Process-per-turn driver implementing AgentAdapter; explicit print-timeout always passed; cancellation through the tree-kill facility; resume by conversation id; per-turn result.

## 6. Architectural constraints
- Only vela-adapters::antigravity and vela-uia may contain Antigravity-specific behavior (ADR-008, ADR-018).
- Never trust exit code or result.status; interpret events, stderr, and Git state.
- Never read, copy, or persist Antigravity credentials or tokens (ADR-016).
- Elements tagged [U] are gated by their spike; do not claim them ready.

## 7. Dependencies / blocked by

- P02 Process tree kill and cancellation
- TK1 Scripted fake agy executable replaying recorded Antigravity behavior

## 11. Acceptance criteria
- [ ] Against the fake agy a turn runs in the given worktree and returns events, a final result, and the parsed conversation id.
- [ ] An explicit print-timeout is always passed and a timeout is reported as a timeout, never as success.
- [ ] Cancellation terminates the process tree through the P02 facility with no orphans.
- [ ] A new session never passes `--conversation`; a resume passes exactly the recorded id.
- [ ] The gated real-environment test reproduces kill and resume (probe P6) and holds `RK-AGY-REAL-ACCOUNT`.

## 12. Required unit tests
- Argument builder always includes `--print-timeout` and the allowlisted environment; conversation-id extraction from the init event; timeout and cancel state machine with a fake clock.

## 13. Required integration tests
- Fake-agy scenarios; the A01 capability probe against the fake agy (help and authentication scenarios); gated real-environment test.
