**Planned labels:** `type:feature` `area:security` `risk:medium` `phase:6` `ready-for-agent`  
**Depth in the DAG:** 5 · **Direct blockers (published, transitively reduced):** F07, F08

> Symbolic key: `X03` · Area: security · Phase: 6 · Risk: medium

## 2. Objective
The user can export a diagnostic bundle that never contains secrets or repository source.

## 3. Requirement IDs

## 4. User-visible behavior
None (no user-visible behavior).
