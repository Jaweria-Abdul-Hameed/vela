# S06: Issue ingestion to an approved-ready graph snapshot with cycle reporting

**Planned labels:** `type:feature` `area:orchestration` `risk:high` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 6 · **Direct blockers (published, transitively reduced):** O01, T01, D03, D04, S01, S02

> Symbolic key: `S06` · Area: orchestration · Phase: 1 · Risk: high

## 2. Objective
Local issues become a validated graph snapshot with parallelization verdicts, cycle errors, and analysis states.

## 3. Requirement IDs
FR-005, FR-006, FR-007

## 4. User-visible behavior
Analysis states (analyzing docs, building DAG, cycle detected, graph ready) shown in the renderer.

## 5. Technical scope
- Ingest through the tracker port; build graph; run safety engine; store layout; GRAPH_INVALID intervention on cycles; analyst hook point (sequential fallback).

## 6. Architectural constraints
- The Orchestrator is the only writer of orchestration state; each transition is one transaction (state plus journal) (ADR-002, ADR-017).
- Events reach the UI only after commit.
- Scheduler never assumes a UI is open.

## 7. Dependencies / blocked by
- O01 Orchestrator actor skeleton: message bus, transactional transitions, run creation, snapshot assembly
- T01 Local Markdown tracker: ticket parsing, blockers, and malformed-metadata handling
- D03 Parallel-safety engine: predicted write sets, hard blockers, evidence labels, resource keys
- D04 Deterministic layered graph layout stored with the snapshot
- S01 Project import: choose a repository, persist it, and list recent projects
- S02 Settings layers, onboarding choices, and the immutable run snapshot

## 11. Acceptance criteria
- [ ] A fixture issue set yields the expected frontier and verdicts; a cyclic set yields GRAPH_INVALID and no snapshot; malformed metadata is flagged.
- [ ] A cyclic set moves the run to NEEDS_HUMAN with kind GRAPH_INVALID through the state machine and stores no snapshot (the full intervention record and resolve flow is the human-intervention ticket).
- [ ] Malformed metadata is flagged.
