# A07: Headless ASK path: spool, APPROVAL_ASK, one-time allow, and resume

**Planned labels:** `type:feature` `area:antigravity` `risk:high` `phase:2` `ready-for-agent`  
**Depth in the DAG:** 8 · **Direct blockers (published, transitively reduced):** A06, SP05, K01

> Symbolic key: `A07` · Area: antigravity · Phase: 2 · Risk: high

## 2. Objective
An ASK-class operation blocks, surfaces as an intervention, and after a human allow-once resumes the conversation with an exact expiring allow rule.

## 3. Requirement IDs
FR-031, AT-011

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
