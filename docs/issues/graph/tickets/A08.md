# A08: Skills detection and bootstrap for worker worktrees

**Planned labels:** `type:feature` `area:antigravity` `risk:medium` `phase:2` `ready-for-agent`  
**Depth in the DAG:** 6 · **Direct blockers (published, transitively reduced):** A01, G03, SP10, G02

> Symbolic key: `A08` · Area: antigravity · Phase: 2 · Risk: medium

## 2. Objective
Required engineering skills are detected and, with user approval, installed at project level without mutating the user branch.

## 3. Requirement IDs
FR-004

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Detect skills at project and global locations; offer install through a bootstrap action on a separate Vela branch; record version or commit; verify callable; handle the setup skill collisions with existing instruction files.
- Returns installation records to its caller; persistence of `skill_installations` belongs to the preflight service (S04 schema, K10 service) because adapter crates never depend on persistence. The bootstrap branch is created through the G02 worktree manager and committed through G03; the preflight skills check is registered by K10.

## 6. Architectural constraints
- Only vela-adapters::antigravity and vela-uia may contain Antigravity-specific behavior (ADR-008, ADR-018).
- Never trust exit code or result.status; interpret events, stderr, and Git state.
- Never read, copy, or persist Antigravity credentials or tokens (ADR-016).
- Elements tagged [U] are gated by their spike; do not claim them ready.
