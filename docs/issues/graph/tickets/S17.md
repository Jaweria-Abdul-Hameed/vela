# S17: Desktop notifications for human-required, failure, and completion events

**Planned labels:** `type:feature` `area:lifecycle` `risk:low` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 6 · **Direct blockers (published, transitively reduced):** O01

> Symbolic key: `S17` · Area: lifecycle · Phase: 1 · Risk: low

## 2. Objective
The user is notified when human action is required, a run completes, or a terminal failure occurs.

## 3. Requirement IDs
FR-028, AT-023

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Notifier port implementation with the Tauri notification plugin; in-app fallback when notifications are denied.

## 6. Architectural constraints
- Background operation, auto-start, and consent are opt-in and persisted (ADR-010, ADR-012).
- Closing the window never silently abandons work.

## 7. Dependencies / blocked by
- O01 Orchestrator actor skeleton: message bus, transactional transitions, run creation, snapshot assembly
