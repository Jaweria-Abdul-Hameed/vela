# U13: Accessibility: graph tree and list, keyboard navigation, focus, and screen-reader labels

**Planned labels:** `type:feature` `area:ui` `risk:high` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 9 · **Direct blockers (published, transitively reduced):** U07

> Symbolic key: `U13` · Area: ui · Phase: 5 · Risk: high

## 2. Objective
Everything the graph shows is available through a navigable DOM tree and full keyboard access.

## 3. Requirement IDs
NFR Accessibility

## 4. User-visible behavior
An always-mounted hierarchical alternative exposing ticket, state, blockers, and dependents; visible focus; discoverable shortcuts.

## 5. Technical scope
- Accessible graph tree; keyboard model across home, universe, inspector, run controls, dialogs; labels for controls and states; non-color status encoding audit; scalable text.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.
