# S02: Settings layers, onboarding choices, and the immutable run snapshot

**Planned labels:** `type:feature` `area:lifecycle` `risk:medium` `phase:1` `ready-for-agent`  
**Depth in the DAG:** 5 · **Direct blockers (published, transitively reduced):** F08

> Symbolic key: `S02` · Area: lifecycle · Phase: 1 · Risk: medium

## 2. Objective
Defaults, user-global settings, project settings, and an immutable run snapshot exist, including the persisted onboarding choices.

## 3. Requirement IDs
FR-040, FR-042, NFR Reliability

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Settings store with the layer order; onboarding keys (background, auto-start, recovery continuation, UI automation consent record); run snapshot capture; project settings stored in Vela, never in the repository.

## 6. Architectural constraints
- Background operation, auto-start, and consent are opt-in and persisted (ADR-010, ADR-012).
- Closing the window never silently abandons work.

## 7. Dependencies / blocked by
