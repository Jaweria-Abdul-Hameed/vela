# F04: Tauri shell walking skeleton with strict CSP and a typed command round trip

**Planned labels:** `type:infra` `area:foundation` `risk:medium` `phase:0` `ready-for-agent`  
**Depth in the DAG:** 2 · **Direct blockers (published, transitively reduced):** F02

> Symbolic key: `F04` · Area: foundation · Phase: 0 · Risk: medium

## 2. Objective
A native Windows window opens the renderer, with a strict content security policy and an allowlisted capability set, and one typed command and one event round-trip between React and the Rust core.

## 3. Requirement IDs
FR-048, FR-047, NFR Security

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- apps/desktop with Vite renderer and src-tauri composition root; tauri.conf.json with strict CSP, no remote content, capability file allowing only the registered command and required plugin permissions.
- One example command (ping) and one event through the contract layer; the build runs as an installed-style window without a localhost server for production.
- Dev command and production build both launch.

## 6. Architectural constraints
- Cargo workspace plus npm workspaces only (ADR-017); no additional monorepo orchestration.
- Crate dependency direction is enforced in CI (IMPLEMENTATION_ARCHITECTURE.md section 3).

## 7. Dependencies / blocked by
- F02 Domain primitives, ports, and TypeScript contract generation

## 9. Known shared contracts
