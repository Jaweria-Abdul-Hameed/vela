# U06: Node states and event-driven effects: ripples, edge flow, settling

**Planned labels:** `type:feature` `area:ui` `risk:medium` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 8 · **Direct blockers (published, transitively reduced):** U05

> Symbolic key: `U06` · Area: ui · Phase: 5 · Risk: medium

## 2. Objective
Node states are communicated by shape, motion, label, and light, and key orchestration events produce purposeful effects.

## 3. Requirement IDs
FR-025, FR-026, AT-008

## 4. User-visible behavior
Running breathes slowly; testing ticks; reviewing has an outer ring; fixing pulses; merging flows along the edge; done settles; blocked shows a lock glyph; failed uses a warm restrained accent; needs-human gets a persistent non-flashing attention treatment.

## 5. Technical scope
- State projection to visuals; event-to-effect mapping (WorkerStarted, TestGateFinished pass, merge, TicketReady, HumanActionRequired); reduced-motion alternatives for every effect.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.
