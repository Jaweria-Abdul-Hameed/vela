# U08: Timeline and evidence panels: commands, tests, review findings

**Planned labels:** `type:feature` `area:ui` `risk:medium` `phase:5` `ready-for-agent`  
**Depth in the DAG:** 9 · **Direct blockers (published, transitively reduced):** U07

> Symbolic key: `U08` · Area: ui · Phase: 5 · Risk: medium

## 2. Objective
Every ticket has an event timeline that expands to command, test, and review evidence derived from real journal records.

## 3. Requirement IDs
FR-023, FR-012, FR-013

## 4. User-visible behavior
A calm timeline with expandable evidence; virtualized logs.

## 5. Technical scope
- Timeline surface from journal events; evidence panels for tests and findings; virtualization for large logs.

## 6. Architectural constraints
- DOM owns all text and controls; only packages/ui/src/canvas imports React Three Fiber/Three.js (ADR-019).
- Not a conventional dashboard: no permanent sidebar, dense card grids, gratuitous glass, or random neon.
- Animation is derived from events or interaction; never authoritative for state.
- Reduced-motion and keyboard behavior are implemented in the same ticket, not later.

## 7. Dependencies / blocked by
- U07 Issue focus transition and inspector with progressive disclosure
