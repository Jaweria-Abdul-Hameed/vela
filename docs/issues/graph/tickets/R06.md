# R06: Sleep, wake, network loss, and GitHub outage handling

**Planned labels:** `type:feature` `area:recovery` `risk:medium` `phase:3` `ready-for-agent`  
**Depth in the DAG:** 12 · **Direct blockers (published, transitively reduced):** R02, T03, P03

> Symbolic key: `R06` · Area: recovery · Phase: 3 · Risk: medium

## 2. Objective
Sleep is a recoverable pause; network and remote failures never corrupt local work.

## 3. Requirement IDs
FR-019, NFR Reliability

## 4. User-visible behavior
None (no user-visible behavior).

## 5. Technical scope
- Elapsed-gap detection on wake; process reconciliation; re-check locks, network, and authentication; push failure paths.

## 6. Architectural constraints
- Persist intent before every non-idempotent external action and the observed result after; never guess after divergence.
- Never replay a stale UI click.

## 7. Dependencies / blocked by
- R02 Startup reconciliation and recovery-resume
- T03 Remote update queue with idempotent retries and outage behavior
- P03 Keep-awake thread and interactive-session probe
