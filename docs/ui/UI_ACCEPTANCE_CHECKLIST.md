# UI Acceptance Checklist

For every major UI PR:

-   [ ] Near-black canvas remains dominant.
-   [ ] Dots are ordered/subtle, not noisy particles.
-   [ ] Pointer response is smooth and bounded.
-   [ ] Violet/blue/cyan ambient light feels volumetric and soft.
-   [ ] Glass is contextual, not everywhere.
-   [ ] No unnecessary permanent sidebar/card grid introduced.
-   [ ] Motion corresponds to interaction/system state.
-   [ ] Reduced motion remains fully usable.
-   [ ] Keyboard path exists.
-   [ ] Focus is visible.
-   [ ] Status is not color-only.
-   [ ] Unfocused/minimized rendering throttles.
-   [ ] No expensive rerender loop.
-   [ ] Text remains crisp.
-   [ ] 100+ graph nodes remain legible/navigable.
-   [ ] Error states preserve the premium visual language without hiding
    urgency.
