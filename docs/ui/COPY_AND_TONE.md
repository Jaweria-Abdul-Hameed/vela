# Product Copy and Tone

Copy should be calm, precise, and operational.

Prefer: - `3 agents running` -
`Issue #24 is waiting for authentication` -
`#31 and #33 both modify the database schema, so Vela will run them sequentially.` -
`Review stopped after 3 iterations. Two correctness findings remain.`

Avoid: - anthropomorphic hype, - "magic," - panic language, - fake
certainty, - celebratory noise, - vague "Something went wrong."

Errors must state: what happened, what Vela knows, what is preserved,
and what action is needed.
