## Known limits (recorded, not blocking)

- **Redaction is a safety net.** It recognizes names, schemes, token shapes, URL user information, PEM private keys and registered values. A secret with no recognizable name or shape and that was never registered is not found (for example the argument of `curl -u user:pass`, or a password printed alone on a line). `CommandSpec` keeps secrets in the environment for that reason, and P01 should register the credential-like environment values of each process (`PatternRedactor::with_environment`).
- **Encodings.** A registered secret is matched as written. Its base64, URL-encoded or otherwise transformed forms are not matched.
- **Multi-line values.** Except for PEM private keys, a value that continues on the following lines (a YAML block scalar) is redacted only on its first line.
- **Name and value pairs in JSON** (`{"name": "DB_PASSWORD", "value": "..."}`) are recognized when the name member comes first, which is the usual serialization.
- **End-to-end test across the two crates.** The corpus runs through the real redactor at every ingestion point inside `vela-process` (plain text, chunked process output, the JSON log layer, serialized journal payloads). `vela-core::diagnostics::redact_payload` is tested with a stand-in port, because `vela-core` cannot use `vela-process` even as a dev-dependency. A test that joins the real redactor to the core port belongs to the composition root (W01) or the security regression suite (X04, `tests/integration/security/regression`).

## Follow-ups for other tickets (not code in F07)

- **F04 / W01:** install the subscriber (`json_layer` over `LogFile`), adapt the shared redactor to `RedactionPort`, route targets to streams.
- **P01:** wrap stdout and stderr in `StreamRedactor`; build the per-process redactor with `with_environment`; choose the line limit for stream-json.
- **O01:** call `redact_payload` on every journal payload before it reaches the writer thread; open a `CorrelationIds` scope per run, worker and operation, and use `spawn_correlated` for worker tasks.
- **X03:** re-redact at export with the same port; retention by age.
